# 安全

[English](../en/security.md) · [项目说明](README.md)

不将签名私钥、用户令牌或秘密放入 Git、插件分发包或普通日志。从经批准的秘密存储注入发布凭据，将每个客户端限制到所需插件标识。密钥文件优先于密钥环境变量。生成的私有 JWKS 应保存在检出目录之外的受保护存储中；若泄露则撤销对应发布客户端。

工具是所配置平台的客户端，由平台执行授权与审核。真实凭据须使用加密连接，使用凭据前验证平台地址。保持 .NET 默认 HTTP 证书验证启用。

通过 [GitHub 私密报告](https://github.com/io7-cn/Quantum.Cli/security/advisories/new)向仓库维护者报告疑似漏洞，不在公开议题中包含真实凭据或敏感插件归档。提供合成复现、受影响版本和预期影响，由维护者协调修复与披露。
